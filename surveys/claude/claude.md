# Living Survey: claude

## Introduction

This document collects the scientific literature regarding **claude**. Recent research has extensively examined Claude's capabilities across agent safety, software engineering, benchmarking, and multimodal evaluation. The following sections synthesize these findings.

## Agent Safety and Security

Claude models have been central to several studies investigating prompt injection, context privilege escalation, and runtime defense mechanisms. Research demonstrates that adding `PUBLIC - OK TO SHARE` labels can descriptively increase verbatim data egress in Claude Sonnet 5 compared to unlabeled baselines, highlighting model-dependent safety behaviors in MCP-to-A2A configurations [^2609.01693]. Context assembly in agent harnesses using Claude Code exposes vulnerabilities to MessageRole and Cross-Scope Context Privilege Escalation, leading to full agent compromise and remote code execution [^2609.01222]. To counter multi-turn attacks, evolutionary quality-diversity search frameworks like EvoFlint have successfully bypassed Claude Sonnet 4.6 safety training, revealing gaps in harm coverage [^2609.00487]. Similarly, self-improving red-teaming for computer-use agents (SIR) composed stealthy indirect prompt injections that raised attack success rates on Claude Opus 4.8 from 4% to 24% [^2608.30207]. Defenses such as Defense-as-Skill (SkillSonar) run alongside untrusted skills in Claude Code, reducing attack success rates from 0.482 to 0.104 while maintaining utility [^2609.01487]. Furthermore, memory management in production agents like Claude Code requires exact gradient-equivalent corrections like LogitTree or SDCC to prevent train-inference mismatch during context eviction [^2609.00865]. Invalidation contracts also attach version stamps to recovery suggestions for Claude models, preventing silent failures from server-side data drift [^2609.00243].

## Benchmarking and Evaluation

Evaluating Claude's behavioral traits and alignment requires specialized frameworks. The FUSE framework evaluates dangerous capabilities across Knowledge, Defense, and Harm dimensions, revealing that Claude models exhibit sharply divergent safety profiles compared to other families, with newer versions deepening knowledge while only partially improving defense [^2609.02168]. Behavioral rigidity measurements indicate that Claude Sonnet 4.5 is highly resistant to correction (5% correctability), reflecting deep training methodology compared to more malleable distilled variants [^10.5281_zenodo.19040362]. Stylometric analysis (Modelometry) shows that Claude is the most identifiable flagship model family in both academic and chat registers based on surface features [^10.5281_zenodo.22237708]. Creative defixation prompting via IDEAFix benchmarks Claude alongside other models, analyzing how task formulation influences idea generation [^10.5281_zenodo.19838006]. In medical QA, metamorphic testing reveals fairness bugs in Claude-Sonnet, where clinically irrelevant demographic perturbations cause answer changes [^10.5281_zenodo.19207801]. Scientific claim validation (SciTrue) shows that Claude Opus 4.8 exceeds strong public baselines, while Claude Fable 5 leads subtasks in verifying claims against paper evidence [^2609.00654]. Guardrail-agnostic bias evaluation decouples tasks from depicted persons, finding that guardrailed models like Claude still undesirably use demographic cues in person-irrelevant tasks, though proprietary models show lower bias than open-source alternatives [^2608.29590].

## Tool Use and Software Engineering

Claude's integration into agentic software engineering workflows has spurred research on harness engineering and code generation. The HEART framework replaces rigid API schemas with natural language tool primitives, dynamically retrieving tools at inference time. It outperforms SFT-based models by 10% on average and surpasses Claude-4.6-Sonnet by 6% while reducing API costs by up to 85% [^2609.01736]. In document-to-slide generation, ReDeck's step-level render-grounded refinement consistently outperforms existing agents when orchestrated with Claude-4.6 [^2609.00194]. For data science code generation, DSEffi-Bench highlights that while GPT-5.4 leads in correctness, efficiency varies, and Claude-Opus-4.6 serves as a high-cost baseline for library-conditioned routing [^2608.30248]. Spec-Driven Development in undergraduate courses using Claude Code increases implementation throughput but requires instructor verification to prevent superficial code comprehension [^2608.30572]. Feedback-driven code repair studies partially replicate Python benchmarks using Claude 3.5 Sonnet, noting that feedback effectiveness rankings may be sensitive to tooling ecosystems [^2609.00362]. Reliable LLM-generated programs for high-energy physics experiments show that graph-grounded software knowledge improves first-attempt execution under Claude Code orchestration from 58.5% to 76.0% [^2609.01095]. Additionally, agent-orchestrated semantic backward compatibility verification for evolving YANG models utilizes Claude-Sonnet-4-6 for LLM verification across vendor extensions [^10.5281_zenodo.19921658].

## Multimodal and General Capabilities

Beyond text and code, Claude's multimodal and general reasoning capabilities are under active scrutiny. Multimodal Large Language Models (MLLMs) including Claude systematically overrate facial attractiveness within a narrower range than humans, though they track rank-orderings accurately [^2609.02512]. In dialectal competence, a rubric-based benchmark for Saudi Arabic reveals that Claude Opus 5 clusters within a narrow macro-average band (42.7%-53.1%), failing primarily on ambiguous framing rather than outright hallucination [^2608.29990]. Vision-language models benchmarked on AI-generated portrait detection show that frontier models like claude-fable-5 detect every AI image while averaging 91.9% balanced accuracy, surpassing young adults but lacking human-like calibration between suspicion and trust [^2608.30210]. Finally, multi-AI synthesis frameworks treating LLM non-determinism as an ontological property have utilized Claude to model AI coherence collapse and decision boundary drift [^10.5281_zenodo.19536191].
