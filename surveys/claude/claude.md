Recent studies highlight evolving safety paradigms for Claude models, particularly in agentic contexts. The Defense-as-Skill framework introduces SkillSonar, a runtime guard implemented as an installable skill that evaluates sensitive actions against task boundaries, significantly reducing attack success rates on Claude Code and OpenClaw while preserving utility [^2609.01487]. Similarly, ECLIPSE demonstrates a self-evolving prompt injection attack against long-horizon agentic systems, achieving high success rates against Claude Code and exposing vulnerabilities in current safety filters [^2608.30441]. EvoFlint applies evolutionary quality-diversity search to multi-turn red-teaming, mapping how target models fail across risk categories [^2609.00487]. Contextual security remains a critical focus, with analyses revealing MessageRole and Cross-Scope Context Privilege Escalation attacks that can compromise real-world harnesses like Claude Code [^2609.01222].
