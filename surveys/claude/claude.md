# Living Survey: claude

## Introduction

This document collects the scientific literature regarding **claude**.

## Agentic Capabilities and Tool Integration

Recent research highlights significant advancements in Claude's agentic frameworks, particularly in tool use and context management. The HEART framework introduces agent-native reusable tool primitives, enabling dynamic tool retrieval and multi-step execution that outperforms several frontier models while reducing API costs by up to 85% [^2609.01736]. To address context assembly vulnerabilities, studies identify novel attack vectors like MessageRole and Cross-Scope Context Privilege Escalation in real-world harnesses, demonstrating how attacker-controlled content can persist or escalate privileges [^2609.01222]. Mitigation strategies include Defense-as-Skill, where runtime guards are implemented as installable skills to check sensitive actions against task boundaries, significantly reducing attack success rates [^2609.01487]. Furthermore, memory management in production agents has been addressed through LogitTree and SDCC corrections, which resolve train-inference mismatches caused by context eviction during rollout [^2609.00865]. Other works explore specialized agent harnesses like Dr. Claw for auditable human-in-the-loop research workflows [^2609.00365] and ReDeck for step-level render-grounded refinement in document-to-slide generation [^2609.00194].

## Safety, Guardrails, and Context Privilege

Evaluating Claude's safety and refusal resilience remains a critical focus. The FUSE framework provides a modular evaluation protocol across Knowledge, Defense, and Harm dimensions, revealing that newer models deepen knowledge while only partially improving defense, indicating that scaling does not uniformly translate to safety [^2609.02168]. Temporal and label-based studies show that public-sharing labels can descriptively increase verbatim data egress in Claude Sonnet 5, highlighting model-dependent safety behaviors [^2609.01693]. Evolutionary red-teaming methods like EvoFlint and SIR demonstrate that multi-turn attacks and indirect prompt injection can bypass guardrails, achieving high success rates on Claude Sonnet 4.6 and Claude Opus 4.8 respectively [^2609.00487, ^2608.30207]. Conversely, guardrail-agnostic bias evaluation methods reveal that despite strong refusals, Claude models still undesirably use demographic cues in person-irrelevant tasks, though proprietary models generally show lower bias than open-source alternatives [^2608.29590].

## Benchmarking, Evaluation, and Behavioral Analysis

Comprehensive benchmarking efforts have quantified Claude's behavioral traits and capabilities across diverse domains. Behavioral rigidity studies indicate that Claude models are consistently the most rigid among frontier LLMs, with low correctability rates that reflect deep training methodologies [^10.5281_zenodo.19040362, ^10.5281_zenodo.19040361]. In multimodal and creative tasks, Claude Fable 5 and Claude Opus 5 demonstrate strong performance, with Fable 5 detecting AI-generated portraits with high sensitivity and Opus 5 scoring competitively on Saudi dialectal competence, though both struggle with pragmatic nuance and register distortion [^2608.30210, ^2608.29990]. Creative defixation prompting via IDEAFix shows that structured design briefs and method-inspired prompts systematically influence Claude's divergent thinking capabilities [^10.5281_zenodo.19838006, ^10.5281_zenodo.19838005]. Additionally, fairness bug detection through metamorphic testing reveals that Claude-Sonnet variants exhibit measurable MR Violation Rates under clinically irrelevant demographic perturbations [^10.5281_zenodo.19207801, ^10.5281_zenodo.19207802, ^10.5281_zenodo.21032824].

## Code Generation and Software Engineering Applications

Claude's integration into software engineering pipelines has been extensively profiled. Benchmarks analyzing task demands reveal that Claude succeeds by matching the scope of gold solutions, with its parity share on files rising significantly at larger scales [^2609.01271]. In code repair, feedback-driven approaches show that while test feedback remains effective, its ranking is sensitive to tooling ecosystems, with lighter prompts reducing costs without sacrificing effectiveness [^2609.00362]. For specialized domains like high-energy physics, graph-grounded software knowledge retrieval improves Claude Code's first-attempt execution from 58.5% to 76.0% [^2609.01095]. In network configuration, YANG-Evolve utilizes agent-orchestrated semantic verification to ensure backward compatibility for evolving models, leveraging Claude-Sonnet-4-6 for LLM-assisted verification [^10.5281_zenodo.19921658, ^10.5281_zenodo.19921659]. Finally, practical implementations in academic settings demonstrate that while AI agent utilization increases implementation throughput, it necessitates rigorous instructor verification to maintain code comprehension [^2608.30572].
