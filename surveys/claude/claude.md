# Living Survey: claude

## Introduction

This document collects the scientific literature regarding **claude**.

## Safety and Red-Teaming
Recent research has significantly advanced the evaluation and hardening of Claude models against adversarial attacks and safety failures. The FUSE framework introduces a modular protocol to evaluate dangerous capabilities across Knowledge, Defense, and Harm dimensions, revealing that newer models deepen knowledge while only partially improving defense resilience [^2609.02168]. To map these vulnerabilities, EvoFlint applies evolutionary quality-diversity search to multi-turn red-teaming, exposing how safety training covers or misses specific harm categories across different model families [^2609.00487]. In the realm of prompt injection, ECLIPSE demonstrates a self-evolving stealthy attack framework that combines direct user-prompt injection with indirect tool-side injection, achieving high success rates even against common safety filters [^2608.30441]. Furthermore, Context Privilege Escalation (M-CPE and X-CPE) attacks highlight how attacker-controlled content can persist or escalate across message roles in real-world agent harnesses, leading to full agent compromise or remote code execution [^2609.01222]. To counter these threats, Defense-as-Skill proposes implementing runtime guards as installable, inspectable skills (e.g., SkillSonar), which successfully reduces attack success rates while maintaining safety-utility trade-offs [^2609.01487]. Additionally, self-improving red-teaming for Compute Use Agents (SIR) composes stealthy injections from reusable principles and iteratively distills bypasses, raising attack success rates significantly over hand-written baselines [^2608.30207].

## Agent Architecture and Tool Use
The architectural evolution of Claude-based agents focuses on robust tool integration, context management, and long-horizon planning. HEART introduces Agent-Native Reusable Tool Primitives, replacing rigid API schemas with natural language interfaces to enable dynamic tool retrieval and multi-step execution, outperforming SFT-based models and reducing API costs by up to 85% [^2609.01736]. Context management remains a critical challenge; MemoryWalker addresses the train-inference mismatch caused by context compression by proposing LogitTree and SDCC corrections, ensuring gradient-equivalent training despite eviction-heavy batches [^2609.00865]. Cross-episode memory reliability is improved through Invalidation Contracts, which attach version stamps to recovery suggestions, allowing clients to evict stale entries without trial-and-error and recovering significant token costs [^2609.00243]. For long-horizon research tasks, Dr. Claw provides an auditable, human-in-the-loop workspace that links persistent state objects and skill libraries to AI executors, improving research completeness and process traceability [^2609.00365]. In specialized domains, RegNetAgents utilizes a multi-agent LangGraph architecture to automate downstream analysis of gene regulatory networks, while GHAgentFiles provides a comprehensive dataset of coding agent file histories to benchmark agent behavior in repository-level tasks [^10.5281_zenodo.18500027][^https:__openalex.org_W7167187963].

## Code Generation and Software Engineering
Claude models continue to demonstrate strong capabilities in software engineering and code generation, though benchmarks reveal nuanced performance characteristics. The Spread-Novelty-Centrality (SNC) profile shows that nominal benchmark labels are unreliable proxies for task demands, with agent behavior revealing hidden demands that human-written gold solutions cannot capture [^2609.01271]. For domain-specific code, grounding LLMs in software knowledge graphs improves first-attempt execution rates for high-energy physics experiments using the ROOT framework [^2609.01095]. Feedback-driven code repair studies indicate that while test feedback remains the strongest signal in Python, its effectiveness varies in Java, highlighting the need for multilingual evaluation frameworks [^2609.00362]. Efficiency in data science code generation is evaluated via DSEffi-Bench, revealing that correctness alone fails to characterize efficiency, with some models achieving higher efficiency scores despite lower pass rates [^2608.30248]. Furthermore, YANG-Evolve leverages agent-orchestrated semantic verification to ensure backward compatibility in evolving network configuration models, demonstrating the utility of LLMs in formal protocol validation [^10.5281_zenodo.19921658].

## Evaluation, Benchmarks, and Bias
Comprehensive evaluation frameworks are essential for understanding Claude's capabilities and limitations across diverse tasks. SciTrue benchmarks multimodal models on scientific claim validation, showing that strong instruction-tuned models like Claude Opus 4.8 and Claude Fable 5 lead in evidence pairing accuracy [^2609.00654]. Behavioral analysis reveals a rigidity spectrum, where Claude models exhibit higher resistance to correction compared to GPT flagships, suggesting differences in training methodology depth [^10.5281_zenodo.19040362]. Stylometric analysis (Modelometry) confirms that Claude maintains a distinct modelolect, achieving high classification accuracy in both academic and chat registers [^10.5281_zenodo.22237708]. Creativity and divergent thinking are assessed via IDEAFix, which evaluates how structured prompting influences idea generation across multiple LLMs [^10.5281_zenodo.19838006]. Bias and fairness remain active research areas; Guardrail-Agnostic evaluation decouples tasks from depicted persons to reliably measure societal bias in LVLMs, while fairness bug detection via metamorphic testing exposes demographic perturbations in medical QA [^2608.29590][^10.5281_zenodo.19207801]. Dialectal competence is also scrutinized, with rubric-based benchmarks for Saudi Arabic revealing that models often fail by distorting register rather than hallucinating facts [^2608.29990].

## Multimodal Models and AI-Assisted Research
Claude's multimodal and assistive capabilities are expanding into visual analysis and collaborative research workflows. Frontier vision-language models, including Claude Fable 5, have surpassed young adults in detecting AI-generated portraits, though they still lag behind humans in calibration and balance between suspicion and trust [^2608.30210]. In academic settings, autoethnographic studies of AI-assisted amateur research highlight the interactional expertise and boundary work involved when using models like Claude Opus 4 as epistemic collaborators, revealing an encouragement-to-criticism ratio that varies by disciplinary verifiability [^10.5281_zenodo.18908883]. Theoretical frameworks also explore AI coherence collapse, modeling non-determinism as an ontological property and proposing metrics like the Silent Authority Transfer to quantify decision boundary drift during substrate updates [^10.5281_zenodo.19536191].
