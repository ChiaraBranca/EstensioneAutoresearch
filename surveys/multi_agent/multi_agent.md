# Living Survey: multi_agent

## Introduction

This document collects the scientific literature regarding **multi_agent**.

## Multi-Agent Architectures and Orchestration
Recent advancements have focused on scalable and heterogeneous multi-agent orchestration. The MOSAIC platform introduces a universal agent-level interface that enables heterogeneous agents (RL policies, LLMs, VLMs, and humans) to operate within shared reinforcement learning environments via an IPC-based worker protocol, facilitating reproducible cross-paradigm comparisons [^https:__openalex.org_W7133365089]. Similarly, Project Synapse employs a hierarchical multi-agent architecture orchestrated by LangGraph, where a central Resolution Supervisor delegates tactical subtasks to specialized workers for autonomous last-mile delivery disruption resolution [^https:__openalex.org_W7124227974]. In software engineering, multi-agent LLM architectures have been adapted for automated front-end generation, coordinating generation, validation, and repair loops to synthesize React applications from design artifacts and user stories [^https:__openalex.org_W7166959618].

## Agent Governance, Trust, and Safety
As multi-agent ecosystems scale, governance and trust mechanisms become critical. The Agent Trust Fabric (RFC-ATF-5) proposes a Cognitive Governance Layer that addresses decision-space verification through counterfactual governance engines and establishes universal governance invariants aligned with major regulatory frameworks [^10.5281_zenodo.20391722]. Trust quantification is further explored through information-theoretic approaches, demonstrating how entropy and mutual information can measure trust in multi-agent cooperative navigation and federated learning pipelines under deceptive conditions [^10.6084_m9.figshare.32101069]. Safety remains a foundational architectural property; the "Internet of Agents" framework deconstructs systemic vulnerabilities across single agents, multi-agent systems, and interoperable ecosystems, advocating for co-designed safety protocols alongside capability expansion [^10.48550_arxiv.2512.00520]. Security and authorization boundaries are rigorously tested by APort Vault, which replays thousands of human-written attacks against live payment agents to evaluate policy configurations and the Open Agent Passport specification, demonstrating near-zero unauthorized transfers behind the authorization layer [^2609.22076]. Containment strategies are formalized through Provisional Reachability, which holds every agent crossing in escrow for auditing and revocation, mathematically bounding information leakage and preventing secret assembly across windows [^2609.21957]. Policy-regulated multi-agent systems are structured by the JustAct framework, providing a Rocq specification and Rust implementation for open-multi-agent environments with enforceable policy constraints [^10.5281_zenodo.21240014]. Enterprise governance is further refined by the Agent Steward concept, which identifies context provenance and temporal validity as a missing architectural dimension to detect silent errors caused by obsolete agent context, introducing the Context Validity Declaration to make obsolescence detectable at runtime [^10.5281_zenodo.21660204].

## Multi-Agent Systems in Specialized Domains
Multi-agent paradigms are increasingly deployed across diverse verticals. In medical intelligence, a state-machine-based multi-agent architecture enables collaborative diagnostic reasoning by having specialized agents analyze evidence, vote, and revise conclusions, significantly improving accuracy on multimodal datasets [^10.3390_math14142562]. Bio-robotics leverages evidence-grounded multi-agent systems to translate application requirements into genetic circuit designs, automating module assembly and conflict checking across extensive biological part libraries [^10.48550_arxiv.2608.19699]. In educational assessment, multi-agent processing combined with NLP clustering automates the categorization and grading of student submissions, reducing manual workload while maintaining human-in-the-loop oversight [^10.54254_2755-2721_2025.30694]. Additionally, conversational multi-agent frameworks are being utilized to evaluate and refine prompts across different LLM families, leveraging collaborative agent interactions to surface prompt weaknesses more effectively than single-model testing [^10.5120_ijca2025925510]. The integration of agents into enterprise and specialized workflows demands rigorous evaluation and value alignment. EnterpriseVal introduces a use-case-level evaluation system that maps metric vectors with confidence bounds to REJECT/CONDITIONAL/SCALE decisions, closing the gap between public benchmarks and deployment readiness [^2609.21841]. In industrial settings, LLM-based systems for root cause analysis of test failures are compared in single-agent versus orchestrated multi-agent configurations, revealing that single-agent setups currently offer faster, lower-cost reporting for practical baseline deployment [^2609.21843]. User-centric design is advanced through Value-Sensitive Delegation, which analyzes tens of thousands of user posts to show that human values are primarily fulfilled at the agent's outputs rather than the operating conditions set around agent runs, emphasizing the need for better oversight mechanisms [^2609.22067]. Social agent realism is explored by investigating personality-tuned LLMs, finding that while fine-tuning improves linguistic diversity, inter-rater agreement limits confidence in behavioral fidelity improvements [^2609.21857]. Finally, TrialAtlas deploys a memory-augmented multi-agent research organization for clinical trial design, coordinating specialized agents for literature synthesis and regulatory precedent analysis to outperform baselines in detecting trial deficiencies and predicting regulatory success [^2609.21859].

## Error Attribution and Reliability
Debugging complex multi-agent interactions requires robust error attribution methods. The ECHO algorithm introduces a hierarchical context representation combined with objective consensus voting to pinpoint agent-level and step-level failures in interaction traces, outperforming binary search and all-at-once evaluation strategies [^10.48550_arxiv.2510.04886]. In systems engineering, multi-agent root-cause diagnosis frameworks construct evidence graphs from system logs to autonomously identify kernel crash origins, demonstrating the efficacy of distributed agent collaboration in complex debugging pipelines [^10.5281_zenodo.19247220]. Finally, quantum and neuromorphic computing techniques are being integrated into multi-agent reinforcement learning to safely explore large solution spaces, enhancing the reliability and explainability of optimal control in autonomous robotics [^2408.03884].

## Agent Memory and Reasoning Mechanisms
Recent research has significantly advanced how agents manage, retrieve, and reason over information. Designer-RSI introduces a continual adaptation framework where a frozen frontier model accumulates and refines reusable procedural memories from user traffic, widening its skill bank through successful and failed executions without weight updates [^2609.22086]. To improve the reliability of memory retrieval, the Memory Decision Layer (MDL) proposes a zero-parameter controller that fuses relevance, reliability, and task risk to explicitly decouple confidence from consistency, drastically reducing hallucination rates under conflicting memories [^2609.22043]. Long-term conversational memory is further addressed by AutoViewMem, which organizes memories into self-configuring, low-overlap semantic views to prevent semantic interference and improve top-K retrieval accuracy [^2609.21940]. In interactive settings, RAVEL employs retrieval-aware online reinforcement learning to optimize question generation policies, dynamically reallocating questioning budgets toward attributes that yield the most useful retrieval evidence [^2609.21924]. Furthermore, opinion dynamics in social simulations are made auditable and controllable through Bayesian Chronicle Agents, which separate belief states from linguistic output and update stances via single Bayesian steps per utterance [^2609.21997].

## Agent Environments and Training Paradigms
The development of robust agents relies heavily on scalable environments and targeted training methodologies. MintAct unifies UI grounding, multi-step navigation, and visual tool use across mobile, desktop, and web platforms, leveraging a scalable reinforcement learning infrastructure that maintains stability under noisy feedback and off-policy drift [^2609.22083]. For software development, CodeMidas scales agentic coding environments by transforming implemented functionality in open-source codebases into executable RL tasks, improving performance across issue repair, whole-program construction, and terminal work benchmarks [^2609.22068]. Hybrid computer-use agents are evaluated in RecreationWorld, a five-platform framework that provides reproducible environments with native GUI control and coding tools, using running references as oracles for hidden behavioral tests [^2609.22000]. In health interventions, an agentic Just-in-Time Adaptive Intervention (JITAI) system autonomously reviews personal sleep and behavioral data to adapt reminders and interventions, demonstrating technical feasibility for personalized health support [^2609.21805].

## Multi-Agent Control, Robotics, and Strategic Games
Coordinated multi-agent systems continue to push boundaries in physical and strategic domains. Multi-Agent Event-Triggered LQG Control addresses shared communication constraints by decoupling optimal control laws across agents while formulating a globally coupled transmission schedule as a mixed-integer linear program, optimized via a receding-horizon scheduler [^2609.21974]. In robotics, MAAP enables collaborative manipulation by treating every robotic arm as a dual-purpose active perception device, predicting role-dependent actions within a single network to significantly boost success rates in multi-wrist scenarios [^2609.21929]. VIRGA coordinates heterogeneous air-ground platforms by converting dual-LiDAR observations into bounded Riemannian fields mediated by a virtual agent with reciprocal elastic feedback, ensuring safe navigation in confined geometries [^2609.21883]. Theoretical multi-agent decision-making is advanced through the Matrix Exponential Fixed-Point Iteration with Annealing (MEFPIA) algorithm, which efficiently searches for equilibrium points in extended Gutoski-Watrous quantum games by avoiding explicit construction of full joint density matrices [^2609.21944].
